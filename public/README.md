# Public Assets

Place your game assets here:

## Required Images

1. **City Background** (`city-bg.png` or `city-bg.jpg`)
   - Isometric city map background
   - Used in main game screens

2. **Character Images**
   - `chad.png` - CHAD character
   - `chubby.png` - CHUBBY character
   - Other character variants

3. **Card Images**
   - Card artwork for different card types
   - Red Light Therapy, OF Model, Penthouse, Sixpack, etc.

4. **Icons**
   - Activity icons (gym, trading, pool, etc.)
   - UI icons

5. **Map Images**
   - `beach-side.png` - Beach Side map
   - `miami-nights.png` - Miami Nights map

## Note

The application will work without these images, but they will enhance the visual experience. 
You can use placeholder images or generate them based on your design requirements.
